OPTIONAL INTEGRATION

Use your CV library from an AI assistant.

MCP lets a compatible assistant search snippets, match postings, and create CV versions through conversation — entirely on this computer.

Connect in three steps

Your files remain on this computer.

  1. 1

    Start CV Studio

    Docker starts the interface and the MCP server together.

    docker compose up --build
  2. 2

    Add it to your assistant

    For Claude Code, run this command once (adjust the path to where you cloned cv-builder).

    claude mcp add cv-builder -- python3 /absolute/path/to/cv-builder/scripts/mcp-server.py
    Editing a config file instead? (Claude Desktop, etc.)

    Add this to your client's MCP config file, then restart the client.

    {
  "mcpServers": {
    "cv-builder": {
      "command": "python3",
      "args": ["/absolute/path/to/cv-builder/scripts/mcp-server.py"]
    }
  }
}
    Using Docker's HTTP transport instead?

    When the container runs with MCP_TRANSPORT=streamable-http, the server is reachable over the network instead of being spawned locally — point a client at it directly.

    claude mcp add --transport http cv-builder http://127.0.0.1:8765/mcp
    {
  "mcpServers": {
    "cv-builder": { "url": "http://127.0.0.1:8765/mcp" }
  }
}
  3. 3

    Try a request

    Your assistant can use the CV tools whenever you ask.

    EXAMPLE PROMPT

    “Match my experience to this job posting, show the strongest snippets, then create a draft named platform-manager.”

What can the assistant do?

  • Search your libraryFind experience by skill, company, or keyword.
  • Match a job postingRank evidence against requirements.
  • Build a CV versionCompose snippets at the right detail level.
  • Manage draftsSave, load, and revise selections.
You stay in control

Nothing is written until you ask the assistant to create or change a version.
