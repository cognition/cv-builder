OPTIONAL INTEGRATION

Use your CV library from an AI assistant.

MCP lets a compatible assistant search snippets, match postings, and create CV versions through conversation.

MCP serverAvailable locally

Connect in three steps

Your files remain on this computer.

  1. 1

    Start CV Studio

    Docker starts the interface and MCP server.

    docker compose up --build
  2. 2

    Add it to your assistant

    For Claude Code, run this command once.

    claude mcp add cv-builder -- python3 /absolute/path/to/resume/scripts/mcp-server.py
    Using another MCP client?

    Connect to http://127.0.0.1:8765/mcp with Streamable HTTP, or configure the Python script as a local stdio server.

  3. 3

    Try a request

    Your assistant can use the CV tools when you ask.

    EXAMPLE PROMPT

    “Match my experience to this job posting, show the strongest snippets, then create a draft named platform-manager.”

What can the assistant do?

  • Search your libraryFind experience by skill, company, or keyword.
  • Match a job postingRank evidence against requirements.
  • Build a CV versionCompose snippets at the right detail.
  • Manage draftsSave, load, and revise selections.
You stay in control

Ask to see suggestions before creating or changing a version.
